COMPLETE DATA FLOW
================================================================================

Step 1: Image/Claim Upload
   User visits: /insurance_claim_image_analyzer.php
   Uploads image + selects insurance type
   ↓
Step 2: Analysis Generation
   System calls InsuranceAnalysisEngine.analyze()
   Returns structured analysis with:
   - insurance_type (enforced)
   - damage_percentage (0-100)
   - estimated_cost
   - recommended_severity (based on type)
   - confidence_score (0-100)
   - consistency_check (true/false)
   - reasoning (mentions INSURANCE_TYPE)
   - admin_review_required: true
   ↓
Step 3: Database Persistence
   ClaimAnalysisPersistenceService.saveAnalysis() stores in DB
   claim_analyses table entry created with:
   - All analysis fields
   - admin_review_required = 1
   - admin_review_completed = 0
   - created_at timestamp
   ↓
Step 4: Admin Notification
   New claim appears in admin dashboard
   Endpoint: /admin/claims/pending
   ↓
Step 5: Admin Review
   Admin clicks "Review" on pending claim
   Redirects to: /admin/claims/{id}/detail
   Shows:
   - All analysis data
   - Safety warnings if applicable
   - Full reasoning
   - Warning: "HUMAN ADMIN DECISION REQUIRED"
   ↓
Step 6: Admin Decision
   Admin selects one of three options:
   1. APPROVE CLAIM → admin_decision = 'APPROVED'
   2. DENY CLAIM → admin_decision = 'DENIED'
   3. REQUEST ADDITIONAL REVIEW → admin_decision = 'NEEDS_ADDITIONAL_REVIEW'
   ↓
Step 7: Decision Recording
   ClaimReviewDashboardController.recordDecision() updates DB
   Sets:
   - admin_review_completed = 1
   - admin_decision = chosen value
   - admin_review_timestamp = NOW()
   ↓
Step 8: Workflow Complete
   Admin returned to dashboard
   Claim removed from "pending" view
   Claim available in completed claims history

DATABASE SCHEMA
================================================================================

Table: claim_analyses

CREATE TABLE claim_analyses (
    id INT AUTO_INCREMENT PRIMARY KEY,
    
    -- Analysis Data (from InsuranceAnalysisEngine)
    insurance_type VARCHAR(50) NOT NULL,
    damage_percentage INT DEFAULT 0,
    estimated_cost INT DEFAULT 0,
    recommended_severity VARCHAR(50) NOT NULL,
    confidence_score INT DEFAULT 0,
    consistency_check TINYINT(1) DEFAULT 1,
    reasoning LONGTEXT NOT NULL,
    
    -- Admin Review Workflow
    admin_review_required TINYINT(1) DEFAULT 1,
    admin_review_completed TINYINT(1) DEFAULT 0,
    admin_decision VARCHAR(255),
    
    -- Timestamps
    analysis_timestamp DATETIME NOT NULL,
    admin_review_timestamp DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- Indexes for efficient queries
    INDEX insurance_type_idx (insurance_type),
    INDEX admin_review_idx (admin_review_completed),
    INDEX created_at_idx (created_at)
) ENGINE=InnoDB CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
