KEY SAFETY FEATURES
================================================================================

1. ✅ INSURANCE TYPE STRICTLY ENFORCED
   - Type determines all analysis logic
   - Type explicitly mentioned in all reasoning
   - Cannot be ignored or bypassed
   - Type-specific severity thresholds applied

2. ✅ LOW CONFIDENCE DETECTION
   - If confidence_score < 50: severity marked as "UNRELIABLE"
   - Consistency check automatically fails
   - Prevents false confidence in uncertain cases
   - Tested and verified

3. ✅ NO AUTOMATIC DECISIONS
   - System ONLY generates structured analysis
   - Human admin MUST review and approve
   - "admin_review_required" flag always true
   - "final_decision_authority" always "HUMAN_ADMIN_ONLY"

4. ✅ CONSISTENCY VALIDATION
   - Checks damage percentage correlates with severity
   - Validates confidence is adequate for severity level
   - Detects logical contradictions
   - Prevents inconsistent recommendations

5. ✅ TYPE-BASED SEVERITY DETERMINATION
   AUTO:     damage >= 70% → MAJOR, >= 40% → MEDIUM, else MINOR
   HOME:     damage >= 70% → MAJOR, >= 40% → MEDIUM, else MINOR
   HEALTH:   serious injury → MAJOR, moderate → MEDIUM, else MINOR
   TRAVEL:   damage >= 80% → MAJOR, >= 40% → MEDIUM, else MINOR
   LIABILITY: serious third-party injury → MAJOR, else MEDIUM
